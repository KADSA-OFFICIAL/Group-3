# 젤리 워즈 (Jelly Wars)

팀 **스틱매너** 의 2인 대전 액션 게임. 두 플레이어가 여러 무기를 사용해 대전하며, 3점을 먼저 얻으면 승리한다.

- **엔진:** Godot 4.6
- **장르:** 액션 (한 화면 2인 로컬 대전)

## 실행 방법

1. Godot 4.6 이상을 실행한다.
2. 프로젝트 매니저에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택.
3. **F5** 를 누르면 타이틀 화면부터 시작된다.

한 기기에서 둘이 같이 한다. 접속이나 서버 준비는 없다.

## 조작

| | 1P | 2P |
|---|---|---|
| 좌우 이동 | A / D | ← / → |
| 점프 | W | ↑ |
| 빠른 낙하 | S | ↓ |
| 특수 공격 | 왼쪽 Shift | Space |

기본 공격은 자동이다 — 근접 무기는 상대에게 닿으면, 원거리 무기는 일정 간격마다 저절로 나간다.
라운드가 시작될 때 뜨는 무기 카드도 같은 키(좌우로 고르고 특수 키로 결정)로 고를 수 있다.

게임 중 **ESC** 를 누르면 타이틀 화면으로 돌아간다.

## 화면 흐름

타이틀 → 선택 창 (1P·2P 캐릭터 선택) → 전투 (라운드마다 무기 선택 → 대결) → 3점 선취 시 결과 → 선택 창

## 진행 상황

- [x] 맵 + 2인 이동 (WASD / 방향키)
- [x] 타이틀 화면, 캐릭터 선택 창
- [x] 무기 17종 — 기본 공격은 자동, 특수 공격은 1P Shift / 2P Space
- [x] 라운드마다 무기 선택 — 후보 3장 중 하나를 1P·2P가 차례로 고른다
- [x] 체력과 사망
- [x] 젤리곰 캐릭터 5종 — 선택 창에서 고른 캐릭터로 싸운다
- [x] 점수 / 3점 선취 승리 — 라운드마다 되살아나고, 먼저 3점을 얻으면 이긴다
- [x] 맵 5종 — 바다 · 화산 · 협곡 · 오두막 · 투기장. 바다와 화산은 떨어지면 죽는다
