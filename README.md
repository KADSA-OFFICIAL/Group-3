# 젤리 워즈 (Jelly Wars)

팀 **스틱매너** 의 2인 대전 액션 게임. 두 플레이어가 여러 무기를 사용해 대전하며, 3점을 먼저 얻으면 승리한다.

- **엔진:** Godot 4.6
- **장르:** 액션 (2인 로컬 대전)

## 실행 방법

1. Godot 4.6 이상을 실행한다.
2. 프로젝트 매니저에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택.
3. **F5** 를 누르면 타이틀 화면부터 시작된다.

## 조작

| | 1P | 2P |
|---|---|---|
| 좌우 이동 | A / D | ← / → |
| 점프 | W | ↑ |
| 빠른 낙하 | S | ↓ |

게임 중 **ESC** 를 누르면 선택 창으로 돌아간다.

## 화면 흐름

타이틀 → 선택 창 (캐릭터/무기/맵 선택) → 전투(평지)

## 폴더 구조

```
scenes/     씬 파일
  title.tscn         타이틀 화면
  select.tscn        게임 준비 선택 창
  player_panel.tscn  선택 창의 플레이어 1인 패널 (양쪽에 재사용)
  main.tscn          전투 화면 (평지 맵)
  player.tscn        플레이어 캐릭터
scripts/    GDScript
  game_state.gd      화면 간 선택 정보 전달 (오토로드 싱글톤)
  jelly_preview.gd   선택 창의 젤리 미리보기 렌더링
resources/  폰트 등 리소스
```

## 진행 상황

- [x] 평지 맵 + 2인 이동 (WASD / 방향키)
- [x] 타이틀 화면, 게임 준비 선택 창
- [x] 무기 17종 — 기본 공격은 자동, 특수 공격은 Shift
- [x] 체력과 사망
- [ ] 추가 맵 (냉장고, 봉지 속, 위 속)
- [ ] 점수 / 3점 선취 승리

머리 장식은 선택 창에서 고를 수는 있지만 아직 전투에 반영되지 않는다.
