# 무기 그림

`scripts/weapons.gd`의 `Weapons.LIST`에서 `file` 필드가 있는 무기만 이 폴더에서 그림을 찾는다.
파일 이름은 그 값과 정확히 같아야 한다.

| 파일 | 무기 |
| --- | --- |
| `sword.png` | 검 |
| `dagger.png` | 단검 |
| `chainsaw.png` | 전기톱 |
| `hammer.png` | 망치 |
| `cannon.png` | 대포 총 |
| `bomb.png` | 폭탄 |
| `bow.png` | 활 |
| `laser_sword.png` | 광선검 |
| `trident.png` | 삼지창 |
| `glove.png` | 글러브 |
| `glove_rocket.png` | 글러브 — 특수로 **날아가는** 글러브 (뒤에 노란 분사) |
| `knuckle_worn.png` | 너클 — 손에 든 모습 (앞으로 뻗은 주먹) |
| `knuckle.png` | 너클 — **대기실 선택창**에만 쓰는 금속 너클 (`preview_file`) |
| `shuriken.png` | 표창 — 손에 든 것과 던진 것 모두 이 그림이다 |
| `shuriken_red.png` | 표창 — 35% 확률로 나오는 **빨간** 표창 (`empowered_file`) |
| `double_axe.png` | 양날 도끼 |
| `double_axe_red.png` | 양날 도끼 — 특수 **쿨타임이 끝났을 때** 드는 빨간 도끼 (`ready_file`) |
| `pole.png` | 장대 |
| `shotgun.png` | 샷건 — 총구가 **왼쪽**이라 `art_faces_left` (전기톱·활과 같다) |

`file` 필드가 없는 무기 2종(소총·방패)은
아직 그림이 없어 전투 화면에서 임시 막대로 그려진다. 그림이 생기면 파일을 여기 넣고
무기 표에 `file` 한 줄만 추가하면 된다.

**선택창 그림이 손에 든 그림과 달라야 하면 `preview_file`을 따로 적는다** (이슈 #173).
너클이 유일한 사례다 — 손에 드는 것은 주먹이고 무기 자체는 금속 너클이라, 한 장으로는
"무엇을 고르는지"와 "무엇을 쥐고 있는지" 중 하나가 반드시 어긋난다. `preview_file`이
없는 무기는 지금까지처럼 `file` 한 장을 양쪽에 쓴다.

## 지켜야 할 것

- **배경은 투명해야 한다.**
- 무기는 세로로(날 끝이 위) 그린다. 캐릭터가 세워 든 모습으로 옆에 놓인다.
  - **날아가는 그림은 예외로 가로(앞이 오른쪽)로 그려도 된다** — `glove_rocket.png`가
    그렇다. 그때는 스폰 데이터에 `"art_points_right": true`를 넘겨야 회전이 맞는다
    (이슈 #161). 안 넘기면 90도 어긋나 주먹이 위를 본다.
- 캔버스 크기와 여백은 맞추지 않아도 된다 — `Art.content_rect()`가 여백을 빼고 잰다.
- 좌우 비대칭인 무기(활 등)는 오른쪽을 보는 기준으로 그린다. 왼쪽을 볼 때는 코드가 뒤집는다.

화면에 그려지는 높이는 `Player.WEAPON_HEIGHT`(현재 56px)이며 캐릭터(72px)보다 조금 작다.

다만 **가로는 `Player.WEAPON_MAX_WIDTH`(현재 80px)를 넘지 못한다.** 가로로 긴 원화는
여기에 먼저 걸려서 세로가 56px보다 작아진다 (전기톱 2.69:1 → 80 × 30). 원화 비율은 그대로
지켜지고, 이 제한이 없으면 몸통(48px)의 3배 폭으로 그려져 캐릭터가 무기에 가려진다.
세로로 긴 무기는 이 제한에 걸리지 않는다.

## 눕혀 드는 무기 (장대)

**장대만 예외로 눕혀 든다** — 무기 표의 `art_held_forward`다. 사거리 판정이 가로
방향이고, 그림이 없던 동안 이 자리를 채웠던 임시 막대도 몸 가운데에서 앞으로 뻗는
가로 막대였다. 세워 들면 늘어나는 방향이 판정 방향과 어긋난다.

원화가 0.113:1(가로:세로)로 아주 가늘고 길어서 세워 들면 6 x 56px, 곧 선 한 줄이 되고
구슬 두 개가 점으로 뭉갠다. 눕히면 같은 크기가 **56 x 6px, 앞으로 뻗은 봉**으로 읽힌다.

특수(사거리 1.6배)가 걸린 동안 `art_grows_with_reach`로 **길이가 1.6배**가 되어 앞으로
90px까지 뻗는다. 굵기는 `Player.ART_THICKEN_SHARE`(0.5)만큼만 따라가 1.3배(6 → 8px)다 —
길이만 늘리면 늘어난 봉이 실처럼 가늘어 보이고, 굵기까지 같은 배율로 늘리면 길어진 것이
아니라 무기가 통째로 커진 것으로 보인다. 뒤쪽 끝(주황 구슬)이 몸에 붙어 있고 앞으로만 자란다.

**그림을 붙이면 임시 막대가 사라진다는 것을 잊지 말 것.** 막대는 길이가 사거리라
사거리 버프가 눈에 보였는데, 그림으로 바꾸면 그 표시가 통째로 없어진다 — 장대가
실제로 그랬고, `art_grows_with_reach`가 그것을 그림 쪽에서 되살린 것이다.

**뭉툭한 원화(가로세로가 비슷한 것)는 두 규칙을 다 통과하고도 몸통만 해진다** (이슈 #158).
세로 56px 규칙이 검처럼 가늘고 긴 무기 기준이라, 정사각에 가까우면 56 × 56에 가까운
덩어리가 되어 젤리(72px)를 덮는다. 그런 무기는 표에 `"weapon_art_scale": 0.6`처럼 배율을
적어 더 줄인다 — 지금은 글러브(1.18:1)·표창(1:1)·너클(1.06:1)이 쓴다.
**판정과는 무관하고 보이는 크기만 바뀐다.**

## 아직 안 쓰는 파일

`sword_charged.png`는 강화 상태 그림으로 보이지만 어떤 상태를 뜻하는지 정해지지 않아
아직 코드에서 쓰지 않는다. (`bomb_charged.png`는 무기 표의 `empowered_file`로 쓰인다.)

## 빨간 그림이 뜨는 계기가 둘이다

- `shuriken_red.png` — **뽑기**(`empowered_file`). 서버가 미리 뽑아 두고, 그 표창을
  들고 있다가 던지면 위치가 바뀐다.
- `double_axe_red.png` — **특수 쿨타임**(`ready_file`). 쿨타임 9초가 끝나 쓸 수 있으면 뜬다.

둘 중 무엇으로 바꿀지 고르는 곳은 `Player._highlight_file()` 한 곳이고, 연기
(`smoke_puffs`)도 같은 판단을 쓴다 — 조건을 두 곳에 쓰면 그림과 연기가 어긋난다.
